# PR plans

PR plans preserve historical or narrowly scoped implementation sequences. They are **not** the top-level current schedule.

For current execution order, use:

1. `docs/governance/document-authority.md`;
2. `docs/project-roadmap.md`;
3. `docs/project-roadmap-2026-08-09-addendum.md`;
4. the applicable active programme roadmap/addendum.

## Historical planning baselines

- [mvp-pr-plan.md](mvp-pr-plan.md) — early MVP sequence retained for traceability.
- [full-roadmap-pr-plan.md](full-roadmap-pr-plan.md) — early M0–M7 / pre-v1 estimate retained for traceability; it is not the current PR numbering or execution schedule.

Do not resume an old PR number merely because it appears in these files. Current Work IDs, source readiness, publication boundaries, and immediate execution order come from the active canonical roadmaps and adopted addenda.
